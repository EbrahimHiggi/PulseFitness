## 💪 Pulse Fitness

Pulse Fitness is a modern and responsive fitness website designed for gyms, fitness centers, and personal trainers.
It provides an engaging user experience with interactive sections, fitness tools, pricing plans, and product showcases to help users start their fitness journey.

## 📌 Features

* Fully responsive design (Desktop, Tablet, Mobile).

* Modern fitness-themed user interface.

* Interactive navigation menu with mobile support.

* BMI (Body Mass Index) Calculator.

* Before & After image comparison slider.

* Dynamic pricing switch (Monthly / Yearly).

* Customer reviews slider powered by Swiper.js.

* Gym schedule section with weekly workout plans.

* Product showcase with interactive hover effects.

* Contact form section with modern UI.

## 🛠️ Technologies Used

* HTML5 – Semantic structure and content.

* CSS3 – Styling, animations, and responsive layouts.

* JavaScript (ES6) – Interactive functionality and dynamic behavior.

* Swiper.js – Responsive testimonial slider.

* Font Awesome – Icons and visual enhancements.
